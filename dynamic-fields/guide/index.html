Dynamic custom fields for any Eloquent model

Attach text, selects, tags, toggles, files, dates, and more to User (or any model) without adding JSON columns. Values live in an EAV table; files live on Spatie Media Library.

What it is

Spiggle Dynamic Fields is a Laravel + Filament plugin that lets administrators define extra fields in the panel, then automatically injects those fields into host resources (forms, tables, infolists).

It is not a public form product. For public capture, use Spiggle Form Builder. The two packages share field-type names; Form Builder can copy Dynamic Fields definitions into a form schema.

Admin users

Create fields in System → Custom Fields, set types and options, clone, and they appear on the target model’s resource.

Developers

Add two traits to a model, call CustomFieldMapper in a Filament schema, and values persist on save.

What is stored

Definitions in custom_fields, options in custom_field_options, values in custom_field_values. Files are Spatie media, not blobs.

Who this is for

  • Filament operators who need extra profile or record attributes without a developer shipping a migration every time.
  • Laravel developers wiring the plugin into a host app (this starter already does that on User).
  • Shield / Spatie Permission admins who will grant manage_custom_fields.

Quick start (already done in the starter)

On a fresh host app:

composer require spiggle/dynamic-fields:@dev
php artisan vendor:publish --tag=dynamic-fields-config
php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="medialibrary-migrations"
php artisan migrate

Register the plugin on the panel, add HasCustomFields (and HasCustomFieldMedia if you use File fields), then map fields into a resource:

use Spiggle\DynamicFields\Filament\DynamicFieldsPlugin;
use Spiggle\DynamicFields\Facades\CustomFieldMapper;

$panel->plugin(DynamicFieldsPlugin::make());

Section::make('Custom Profile Data')
    ->schema(CustomFieldMapper::makeFormFields(User::class));

Full steps, Shield, and seed commands are in the usage guide.

Related plugin

Spiggle Form Builder (spiggle/form-builder v1.0.0) builds public forms. It reuses Dynamic Fields types via FieldCatalog when this package is installed. Submissions do not write to custom_field_values.
