Everything between design and delivery

One plugin for operators who build forms and developers who need a portable schema plus a headless-friendly renderer.

01

Visual schema builder

Settings, Builder, and Preview tabs in Filament. Nested sections and fields are labeled, collapsed, and drag-reorderable.

02

Flexible layouts

Single page, wizard with step gates, tabs, or sequential pages with session drafts — pick the interaction that fits the form.

03

Public Livewire renderer

Serve forms at a configurable prefix (default /forms/{path}) without depending on Filament CSS on the public site.

04

Submission inbox

Status tabs, field-contains filters, date ranges, bulk archive/status/export, plus charts on form and list views.

05

Exports that ship

CSV, Excel-compatible XML, and simple PDF via a queued job — ready for ops teams and compliance handoffs.

06

Dynamic Fields aware

Reuses Spiggle Dynamic Fields types when installed. Import definitions with Form::importCustomFields($ids) into a form schema.

From schema to submissions

A short path from package install to a live public form.

1

Install & register

Require the package, publish config, migrate, and register FormBuilderPlugin (optionally with Dynamic Fields).

2

Design in Filament

Create a form, choose a layout, add sections and fields, preview, then publish with a stable public path.

3

Capture & export

Visitors submit on the public page. Operators review in Submissions, filter, and export CSV / Excel / PDF.
